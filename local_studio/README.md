# 장면집 · 로컬 쇼츠 스튜디오

REA로 조사한 EasyCut의 사용자 흐름을 참고해 독립 구현한 Windows 로컬 앱입니다.

## 실행

Windows에서는 `start.cmd`를 더블클릭하고 http://127.0.0.1:8767 을 여세요. 서버 창을 닫으면 종료됩니다. 포트가 사용 중이면 이미 실행 중인지 먼저 확인하세요.

다른 PC 준비: Python 3.11 이상, FFmpeg/ffprobe를 PATH에 설치하고 아래 명령을 실행합니다.

```powershell
python -m pip install -r requirements.txt
python make_demo.py
python server.py
```

자동 자막은 캐시된 faster-whisper 모델을 CPU에서 사용합니다. 모델이 없으면 오류 안내 후 SRT를 사용할 수 있습니다. 모델을 처음 받을 때만 인터넷 연결이 필요합니다.

```powershell
python -c "from faster_whisper import WhisperModel; WhisperModel('small', device='cpu', compute_type='int8')"
```

## 사용 순서

1. 영상 불러오기에서 파일 또는 이 PC 경로를 선택합니다. 원본을 복사하고 브라우저용 미리보기를 만듭니다.
2. 자동 자막을 만들거나 SRT를 불러옵니다. 자막은 원본 시각을 기준으로 수정합니다.
3. 구간 찾기로 후보를 고르거나 시작/끝을 직접 지정합니다. 후보는 키워드·발화 밀도·문장 경계 기준이며 바이럴 확률이 아닙니다.
4. 제목, 하단 문구, 템플릿 4종, 전체 맞춤/가운데 채움, 0.5~2배속을 설정합니다. 새 프로젝트는 ‘다크 · 제목 안전형’으로 시작하지만, 기존 프로젝트의 템플릿 선택은 유지됩니다.
5. 저장하면 PC에 프로젝트가 남습니다. 되돌리기/다시 실행과 브라우저 임시 초안 복원도 지원합니다.
6. MP4 내보내기를 누르면 저장 후 렌더링합니다. 오른쪽 결과에서 MP4/SRT/썸네일/편집 설정을 다운로드합니다. 이전 출력은 유지됩니다.

제목이 길다면 ‘다크 · 제목 안전형’을 선택하세요. 단어 단위 줄바꿈과 글자 크기 조절로 상단 검은 영역에 최대 두 줄을 배치합니다. 내보낸 MP4의 첫 화면과 썸네일에서 제목이 잘리지 않았는지 확인하고, 작거나 답답하면 제목을 줄이세요. 브라우저 미리보기와 최종 출력의 글꼴은 조금 다를 수 있습니다.

## 파일과 한계

- `data/<프로젝트>/project.json`: 편집 상태. 원본 복사와 미리보기도 같은 폴더에 저장.
- `data/<프로젝트>/exports/<버전>/`: 영상, 자막, 썸네일, 설정. 실패한 렌더의 중간 파일도 남을 수 있습니다.
- 서버는 127.0.0.1에서만 열립니다. 미디어·자막은 외부 API로 보내지 않습니다. YouTube 가져오기를 선택했을 때만 해당 서비스에 접속합니다.
- 출력은 1080×1920 H.264/AAC, 단일 연속 구간입니다. 다중 클립 연결, 얼굴 추적, 댓글 이미지, 자동 게시, EasyCut 서버 AI와 같은 결과는 지원하지 않습니다.
- 미리보기는 브라우저 글꼴 렌더링이므로 최종 자막 줄바꿈/글꼴과 차이가 있습니다. 오른쪽 출력 영상으로 최종 확인하세요.
- 긴 영상 복사·미리보기·음성 인식은 시간이 걸립니다. 현재 작업 취소와 서버 재시작 후 작업 재개는 지원하지 않습니다. 저장된 프로젝트와 완료 출력은 유지됩니다.
- YouTube 다운로드는 선택 기능이며 원격 제한/로그인 요구에 따라 실패할 수 있습니다. 해당 경우 로컬 파일을 사용하세요.
- 데모는 테스트 패턴·작은 신호음과 예제 SRT입니다. 음성 인식 성능을 보여주는 영상은 아닙니다.

## 검증

프로젝트 루트에서 `python -m unittest discover -s local_studio/tests -v`, `python local_studio/smoke_test.py`, `node --check local_studio/static/app.js`.
검사 결과는 `test-results/`에 기록합니다. 이 테스트 영상은 게시용 콘텐츠가 아닙니다.
