# 처음 한 번: Claude Code용 BAT 실행기 만들기

아래 내용을 Claude Code에 붙여 넣으세요. 아직 제작 요청이며 실행기가 이미 완성됐다는 뜻은 아닙니다.

```text
너는 Windows용 영상 제작 자동화 개발자다.
내 목표는 바탕화면의 BAT 파일을 더블클릭하면 PowerShell 터미널이 열리고,
Claude Code와 고니 독립 영상 엔진이 연결되어 롱폼을 숏폼으로 만드는 것이다.

[참고]
고니 엔진: https://github.com/qwer777qq/goni-shortform-highlights
고니 스킬: https://github.com/qwer777qq/goni-skill
독립 엔진 사용법: https://github.com/qwer777qq/goni-shortform-highlights/blob/main/docs/standalone-reel.md

[완성할 사용 순서]
1. 바탕화면의 '고니 숏폼 시작.bat'을 더블클릭한다.
2. PowerShell 창에서 Claude Code, 로그인 상태, Python, Git,
   FFmpeg·ffprobe, 고니 엔진, goni-reel MCP 연결 상태를 확인한다.
3. 빠진 것이 있으면 무엇을 어디서 설치하거나 로그인할지 쉽게 안내한다.
   이미 정상 설치된 것은 다시 설치하지 않는다.
4. 롱폼 파일을 선택하거나 경로를 붙여 넣을 수 있게 한다.
   목표 편수·길이·가로/세로 비율·원하는 스타일을 입력한다.
   기본값은 세로 9:16, 30~60초, 1편이다.
5. 선택된 파일과 요청을 Claude Code 세션에 안전하게 전달한다.
   Claude가 실제 영상·음성 또는 시간 정보가 있는 자막을 확인하고,
   의미가 통하는 장면을 선정해 고니 MCP 또는 CLI로 편집·출력한다.
6. 터미널에 준비·분석·편집·출력·검수 상태와 오류를 이해하기 쉽게 보여준다.
7. 완료 시 출력 폴더를 열고 MP4·편집 설정·검증 결과 위치를 안내한다.
   외부 플랫폼 게시나 계정 변경은 하지 않는다.

[구현 조건]
- BAT는 PowerShell 실행기로 만들고 본 작업은 별도 .ps1에 작성한다.
  사용자가 창의 진행 과정과 오류를 볼 수 있게 유지한다.
- BAT와 PowerShell 파일은 함께 전달하고, BAT가 있는 위치를 기준으로
  경로를 찾는다. 공백·한글·특수문자가 있는 경로를 실제로 시험한다.
- Claude Code 실행 옵션은 설치된 버전의 claude --help로 확인한다.
  로그인은 사용자가 공식 Claude 화면에서 직접 진행하게 하고,
  비밀번호·토큰을 스크립트, 로그, GitHub에 저장하지 않는다.
- Claude 및 엔진 실행은 인수를 안전하게 전달하고 임의 명령 문자열로
  연결하지 않는다. 관리자 권한, 실행 정책 영구 변경, 권한 검사 전체
  건너뛰기는 사용하지 않는다. 필요한 권한 요청은 화면에 표시한다.
- 기존 MCP 등록이 올바르면 재사용한다. 잘못된 등록은 차이를 보여 주고
  다른 설정이나 다른 프로젝트를 건드리지 않는다.
- 같은 원본과 기존 출력은 덮어쓰지 않고 새 작업 폴더에 저장한다.
  실행을 여러 번 해도 설치·등록이 중복되거나 설정이 손상되지 않게 한다.
- 인터넷이 필요한 Claude 서비스와 최초 설치는 연결·인증 상태를
  분명히 표시한다. 로컬 렌더 자체와 Claude 사용 조건을 구분한다.
- 상태 파일·임시 파일은 작업별로 구분한다. 실패하면 성공으로 표시하지
  말고 오류, 재시도 방법, 남아 있는 결과를 안내한다.
- 사용자가 닫거나 취소할 수 있게 한다. 중단된 렌더의 자동 복구가
  실제로 구현되지 않았다면 복구되는 것처럼 설명하지 않는다.

[영상 품질과 범위]
- 확인한 영상·음성·자막 범위와 구간 선정 이유를 기록한다.
  원본을 읽지 못하면 장면이나 대사를 추측하지 않는다.
- 고니의 현재 기능과 미구현 기능을 먼저 확인한다. 현재 독립 릴스
  엔진의 자동 자막·인물 분리·복제·자동 박자 편집은 미구현이다.
- 사용자가 자막을 요구하면 실제 사용 가능한 자막 도구와 결합해
  구현하고 싱크를 검수한다. 불가능하면 누락을 명확히 설명한다.
- 결과 MP4를 실제로 열어 길이·비율·음성 트랙, 컷의 시작·중간·끝,
  자막이 있다면 정확도와 가림을 확인한다. 청취하지 않았다면 밝힌다.

[반드시 직접 검증]
- 새 설치와 기존 설치, 로그인 필요, MCP 누락, FFmpeg 누락,
  잘못된 파일, 취소, 작업 실패, 기존 결과 보존을 확인한다.
- 한글·공백 경로에서 BAT를 실제 더블클릭해 PowerShell 실행을 확인한다.
- 테스트 영상으로 Claude 연결 → 입력 → 편집 → MP4 출력까지 검증한다.
  실제 인증이나 미디어가 없어 전체 검증이 막히면 어느 단계까지
  확인했는지와 남은 단계를 구분한다.
- 바탕화면에 BAT, PS1, 초보자 사용법, 테스트 결과를 모아 준다.
  GitHub 반영을 요청받았다면 비밀값·영상·개인 경로는 제외한다.
```
