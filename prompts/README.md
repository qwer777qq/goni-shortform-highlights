# 상황별 프롬프트: 하나만 골라 복사하세요

| 상황 | 사용할 프롬프트 | 붙여 넣을 곳 |
| --- | --- | --- |
| 처음 시작, BAT 실행기 만들기 | [1. Claude BAT 설치·제작 요청](01-claude-bat-setup.md) | Claude Code |
| 설치 후 롱폼에서 쇼츠 만들기 | [2. 영상 제작 요청](02-make-short.md) | Claude Code 또는 Codex |
| 말 자막이 필요한 강의 영상 | [3. 자막 강의 쇼츠 요청](03-caption-short.md) | Claude Code 또는 Codex |
| 이미 만든 영상 수정 | [4. 결과 수정 요청](04-revise-short.md) | 기존 작업을 계속하는 Claude Code 또는 Codex |

각 문서의 코드 상자를 통째로 복사하고 `[대괄호]`만 내 정보로 바꿉니다. 한 번에 전부 붙여 넣지 않아도 됩니다. BAT는 이 프롬프트로 **만들어 달라고 요청하는 기능**이며, 이미 제공된 실행 파일이라는 뜻은 아닙니다.

Claude Code 또는 Codex가 내 PC의 파일·도구를 사용할 수 있어야 실제 MP4를 만들 수 있습니다. 링크만으로 원본이 확인되지 않으면 영상 파일이나 시간 정보가 있는 자막이 필요합니다. 현재 독립 릴스 엔진은 자동 자막·인물 분리·자동 박자 편집을 지원하지 않습니다. [엔진 설치와 기능](../docs/standalone-reel.md).
