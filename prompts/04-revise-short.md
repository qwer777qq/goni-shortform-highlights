# 4. 이미 만든 영상 수정하기

기존 MP4와 가능하면 편집 설정 파일을 함께 알려 주세요.

```text
내가 만든 쇼츠를 확인하고 아래 내용만 수정해 줘.
영상: [기존 MP4 경로]
편집 설정: [JSON 또는 프로젝트 ID / 없으면 없음]
바꿀 점: [예: 첫 장면을 2초 줄이고 제목을 짧게]
유지할 점: [예: 원음과 화면 비율]

실제 파일을 열어 요청을 확인하고 기존 버전은 보존해 줘.
수정이 가능한 도구를 확인한 뒤 새 버전으로 출력해 줘.
바뀐 부분과 시작·중간·끝, 컷 경계, 음성·자막 확인 결과를 알려줘.
실제로 수정하거나 확인하지 못한 항목은 구분해 보고해 줘.
외부에 게시하지 마.
```
