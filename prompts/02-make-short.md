# 2. 롱폼에서 쇼츠 만들기

설치를 마친 후 영상 제작을 요청할 때 사용합니다.

```text
내 롱폼에서 쇼츠를 만들어 줘.
원본: [PC 영상 파일 경로 또는 접근 가능한 영상 링크]
주제: [예: 초보자를 위한 AI 영상 편집]
길이와 편수: [예: 30~60초 1편]
비율: [기본: 세로 9:16]
스타일: [예: 깔끔한 화면, 중요한 장면에만 효과]
반드시 넣을 것: [없으면 없음]
제외할 것: [없으면 없음]

실제 영상·음성 또는 시간 정보가 있는 자막을 확인하고 확인한 범위를 알려줘.
앞뒤 맥락을 살려 이해하기 쉬운 구간을 고르고, 선택 이유와 원본 시간을 기록해 줘.
goni-reel MCP의 standalone 상태와 출력 가능 여부를 확인해 줘.
가능한 기능으로 편집하고 MP4·편집 설정·검증 결과를 전달해 줘.
자동 자막이나 인물 분리 등 현재 지원하지 않는 효과는 완료했다고 말하지 마.
파일을 실제 확인할 수 없거나 출력이 실패하면 그 사실을 알려줘.
원본과 이전 결과를 보존하고 외부에 게시하지 마.
```
