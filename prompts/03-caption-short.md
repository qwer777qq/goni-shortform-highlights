# 3. 자막이 필요한 강의 쇼츠

강사의 말을 읽을 수 있게 자막을 넣고 싶을 때 사용합니다.

```text
아래 강의에서 자막이 있는 쇼츠를 만들어 줘.
원본: [PC 영상 파일 경로 또는 접근 가능한 영상 링크]
자막: [SRT 경로 / 없으면 없음]
주제와 시청자: [예: AI를 처음 배우는 사람]
길이와 편수: [예: 30~60초 1편]
강조할 내용: [없으면 실제 핵심 장면 기준]
가릴 정보: [예: 이메일, API 키 / 없으면 없음]

먼저 원본과 자막을 실제로 확인하고 맥락이 이어지는 구간을 선택해 줘.
사용 가능한 자막 도구를 확인해 SRT를 가져오거나 지원되는 음성 인식을 사용해 줘.
기본 자막 편집기는 연속 한 구간을 출력하며, 독립 릴스 엔진의 자동 자막은 미구현이다.
이름·숫자·제품명과 자막 싱크를 원음과 대조하고 얼굴·중요 화면을 가리지 않게 해 줘.
MP4와 SRT, 편집 설정·검증 결과를 가능한 범위에서 전달해 줘.
자동 가림이나 자막 도구가 불가능하면 완료했다고 말하지 말고 필요한 조치를 알려줘.
원본과 이전 결과를 보존하고 외부에 게시하지 마.
```
