# 고니 숏폼 실행기

1. `start-goni.bat`과 `start-goni.ps1`을 같은 폴더에 둡니다.
2. `start-goni.bat`을 더블클릭합니다. PowerShell 창이 열리면 영상 파일의 전체 경로를 붙여 넣습니다. 빈칸이면 취소합니다.
3. 주제·길이·비율을 입력합니다. 길이와 비율은 Enter를 누르면 기본값을 사용합니다.
4. Claude Code가 열리면 필요한 파일·도구 권한 확인을 읽고 선택합니다. 진행과 결과는 Claude 화면에 표시됩니다.
5. 바탕화면에 생성된 `고니 쇼츠 작업 ...` 폴더의 MP4와 결과 기록을 확인합니다. Claude 세션 종료 후 MP4가 있으면 해당 폴더가 열립니다.

이 실행기에는 Claude Code, FFmpeg, 고니 MCP가 포함되어 있지 않습니다. Claude Code 로그인, FFmpeg·ffprobe PATH, `goni-reel` MCP 등록이 필요합니다. [설치와 MCP 등록](https://github.com/qwer777qq/goni-shortform-highlights/blob/main/docs/standalone-reel.md). Claude 계정·네트워크·권한 확인이 필요하며 원본 영상 확인이 실패하면 숏폼 자동 완성을 보장하지 않습니다. 영상 경로·요청은 결과 폴더에 JSON으로 저장됩니다.

현재 릴스 엔진은 자동 자막, 인물 분리·복제, 자동 박자 편집을 지원하지 않습니다. Claude가 실제로 분석·출력·검수한 범위를 확인하세요. 강의 영상의 의미 분석에는 접근 가능한 영상 또는 시간 정보가 있는 자막과 적합한 도구가 필요합니다.

BAT는 현재 실행할 PowerShell 프로세스에만 `-ExecutionPolicy Bypass`를 지정하며 시스템 실행 정책을 영구 변경하지 않습니다. 조직 정책으로 실행이 제한된 PC에서는 관리자에게 문의하세요. Claude 권한 모드는 `default`로 실행합니다. 사용자 승인 요청을 자동 건너뛰지 않습니다.
