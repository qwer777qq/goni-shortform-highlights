# 고니 | 숏폼 하이라이트 제작

영상과 의도만 주면 에이전트가 자막 확보→맥락 분석→하이라이트 선정→편집→검수를 이어간다. 이미 주어진 목적·길이·개수·스타일은 재질문하지 않는다. 미지정이면 기본 35~60초, 다른 관점의 최대 3개를 목표로 하되 내용이 부족하면 개수를 줄인다.

## 입력과 구성

1. 프롬프트에서 시청자·강조점·제외 항목·CTA를 추린다. 링크와 로컬 파일을 구분하고 실제 영상/자막 접근을 확인한다. 접근할 수 없으면 파일 또는 타임코드 자막을 요청한다. 제목·설명만 보고 시청했다고 하거나 타임코드를 지어내지 않는다.
2. 전체 자막과 주제 흐름을 읽는다. 긴 자료는 타임코드를 유지한 덩어리별 요약과 전체 주제 지도를 사용한다. 규칙 기반 추천 점수를 바이럴 확률이나 의미 판단의 정답으로 취급하지 않는다.
3. 후보의 앞뒤 맥락·컷 경계를 실제 음성과 표본 프레임으로 확인한다. 훅→핵심→증빙/시연→자연스러운 마무리가 성립해야 한다. 부정문·한정 조건·수익 주장 범위를 보존하고 중복 관점·침묵·로딩만 있는 장면을 피한다.
4. 원본 시작/끝 초, 실제 발화, 선정 이유, 짧은 제목, 자막 수정, 썸네일 문구, CTA를 구성표로 남긴다. 원본 발화와 새 화면 문구를 구분하며 의미를 바꾸는 발화 재조합을 하지 않는다.
5. 구성만 요청했다면 구성표·복사용 프롬프트를 전달한다. 영상 제작까지 요청했고 입력이 갖춰졌으면 출력까지 계속한다.

## 로컬 실행

[장면집 연결](references/local-studio.md)을 읽고 현재 프로젝트의 local_studio를 사용한다. 도우미 `scripts/studio_client.py`가 자막 준비와 선정된 구간의 순차 출력을 지원한다. **후보의 의미 판단은 에이전트가 수행한다.** 앱 자체가 영상만 받아 AI로 여러 쇼츠를 자동 완성한다고 소개하지 않는다. 현재 렌더러는 단일 연속 구간만 지원한다. 비연속 조합이 필요하면 지원하는 기존 편집 파이프라인을 사용하거나 해당 기능을 개발·검증한다.

Codex/Claude의 파일·셸·영상 도구 지원을 실제로 확인한다. 연결되지 않은 환경에서 처리 완료로 주장하지 않는다. 기본은 로컬 자막 처리이며 외부 AI API에 영상 업로드나 API 키 설정을 자동 요구하지 않는다.

## 썸네일·검수·납품

프로젝트 AGENTS.md와 저장된 제작 원칙을 먼저 적용한다. AI 자동화 공장장 작업은 consolework-shorts와 메모리의 최신 레이아웃을 따르되 타 채널에 해당 얼굴·브랜드·수익 문구를 자동 적용하지 않는다.

실제 내용과 연결된 짧은 문구, 사용 범위가 확인된 얼굴/로고, 해당 채널의 색상 원칙으로 썸네일을 구성한다. 이미지 제작 도구의 지침을 따른다. 16:9 공유 썸네일과 9:16 첫 프레임을 용도에 맞게 검수한다. 자동 추출 첫 프레임은 브랜드 썸네일 완성품이 아니다.

제목이 길거나 두 줄이면 장면집의 `safe`(다크 · 제목 안전형)를 선택한다. 새 프로젝트의 기본값만 안전형이며 기존 프로젝트가 선택한 템플릿은 유지한다. 영상 전체 디코딩, 길이/해상도/오디오, 컷 경계·음성/자막 싱크, 첫/중간/끝 프레임과 제목이 영상 경계를 넘지 않는지 확인한다. MP4/SRT/썸네일/편집 설정과 선정 근거를 납품한다. 게시와 공개는 현재 사용자가 요청한 대상·범위를 따른다.
